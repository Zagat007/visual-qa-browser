## Границы статуса

- Windows `RUN.bat`/`STOP.bat` и антивирус пользователя здесь не исполнялись: Windows acceptance — **NOT VERIFIED**. Распаковать r7 в новую папку и выполнить `RUN.bat` на целевой машине.
- Производственный сайт пользователя и авторизованные/private страницы не проверялись этим прогоном. Синтетические фикстуры проверяют известные позитивные и негативные сценарии, но не доказывают полноту поиска ошибок на произвольном сайте. Для измерения precision/recall нужен размеченный набор реальных страниц и ошибок.
- Проверка приватных адресов выполняется перед browser request через DNS. Между проверкой и фактическим подключением Chromium DNS может измениться (rebinding/TOCTOU). Без закрепления адреса на уровне соединения нельзя заявлять защиту от злонамеренного домена абсолютной. Аудируйте только сайты, которым доверяете; Safe Mode блокирует обнаруженные private targets и мутационные методы, но не является сетевой песочницей общего назначения.
- Геометрия карусели и качество портретов остаются эвристиками; визуальные CAND и группы RC требуют подтверждения по изображению и исходникам. Внешний AI Art Director — advisory-слой, а не формальный визуальный PASS.

Статус r7: проверенная локальная работоспособность на Linux и управляемых сценариях; «безупречно на всех сайтах/Windows/всех угрозах» не установлено.
