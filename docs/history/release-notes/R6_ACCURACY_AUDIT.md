# Аудит точности и передачи результатов — r6, 2026-10-02

## Воспроизведённые проблемы

1. Реестр `defects.json` собирал находки всех модулей, даже если модуль исключён из scope. Вердикт учитывал scope, поэтому отчёт и список для GPT могли противоречить друг другу. Теперь реестр фильтруется по выбранным модулям; тест VISUAL-only исключает ошибку RUNTIME.
2. Технический промпт был только текстом. GPT не получал скриншоты и не мог независимо проверить кадрирование, наложения и другие визуальные наблюдения. Теперь отчёт содержит ссылку на локальный `gpt-evidence.zip`: BUG-ID, JSON, доступные full-page screenshots, а при включённом Art Director — section screenshots и Art-файлы. `evidence-manifest.json` перечисляет включённые и недоступные изображения, а также BUG-ID без точного screenshot.
3. Пересечение DOM-рамок могло выглядеть для получателя как подтверждённый визуальный баг. Теперь эвристический overlap — «ТРЕБУЕТ ПРОВЕРКИ», а группы RC прямо обозначены гипотезами. Кадрирование и варианты типографики также требуют визуальной оценки.
4. Резервное копирование текста в `report.html` могло показать «Скопировано» при возвращённом `false` от `execCommand`. Теперь оно сообщает об ошибке. Отдельный тест исполняет скрипт отчёта с отказом Clipboard API.

## Доказательства и границы

- `npm run static:check`: PASS; 91 обязательный файл, 77 TS/TSX проверены на объявленные imports.
- `npm run typecheck`: PASS.
- `npx vitest run --exclude tests/browser-engine.test.ts --exclude tests/audit-runtime.test.ts --exclude tests/safe-mode.test.ts --exclude tests/performance-browser.test.ts`: 23 файла / 99 тестов PASS, включая сценарии области аудита, кандидата, манифеста ZIP и отказа clipboard.
- `npm run build`: PASS; frontend и server.
- 4 браузерных файла / 8 тестов, полный `selftest`, `smoke:runtime`, Windows r6: NOT VERIFIED в этой среде. Chromium Playwright здесь отсутствует; загрузка browser shell завершилась повреждённым/неполным ответом. Никакой PASS этим проверкам не присвоен. На Windows запустить `RUN.bat`/`VERIFY.bat` из чистой папки r6.
- Точность на реальных пользовательских сайтах количественно неизвестна: нужен набор размеченных страниц с известными багами и ожидаемыми отсутствиями, чтобы измерить precision/recall. Синтетический тест доказывает корректность классификации и передачи конкретных сигналов, но не качество всех эвристик на произвольном сайте. Manual Art Director и внешний AI — отдельная advisory-оценка, не формальный visual PASS.

Предыдущие r5 runtime/Windows результаты в других документах относятся к r5 и не заменяют проверку r6.
