# r10 — контролируемая калибровка точности

Дата: 2026-10-02. Это первая воспроизводимая **collector-level** калибровка, а не оценка качества на произвольных сайтах.

## Метод

`benchmarks/accuracy-cases.ts`: 35 вручную размеченных HTML случаев, 7 сигналов, позитивные и негативные варианты. Каждый случай рендерится в Chromium 140 на 390×844, DPR 1; запускается реальный сборщик geometry/images/typography, пишется PNG, сравнивается фактический бинарный сигнал с ожиданием. Команда `npm run benchmark:accuracy` сохраняет `results.json`, `report.md` и 35 PNG в `reports/accuracy-benchmark/`. В полном `npm run verify` benchmark исполняется с временным выводом и не меняет дерево исходников.

| Сигнал | Случаи | TP | TN | FP | FN |
|---|---:|---:|---:|---:|---:|
| horizontal-overflow | 5 | 2 | 3 | 0 | 0 |
| zero-size-interactive | 9 | 2 | 7 | 0 | 0 |
| clipping-candidate | 6 | 2 | 4 | 0 | 0 |
| broken-img | 4 | 2 | 2 | 0 | 0 |
| duplicate-img-url | 4 | 2 | 2 | 0 | 0 |
| typography-h2-variant | 4 | 2 | 2 | 0 | 0 |
| crop-candidate | 3 | 1 | 2 | 0 | 0 |
| **Итого** | **35** | **13** | **22** | **0** | **0** |

На **этом фиксированном наборе** precision=13/(13+0)=100%, recall=13/(13+0)=100%. Значение нельзя переносить на реальные сайты: набор мал, выбран вручную и оценивает обнаружение измеримого сигнала, а не истинную первопричину, визуальную значимость или качество советов Art Director. `clipping`, `duplicate-img-url`, `typography-h2-variant`, `crop-candidate` остаются CAND.

## Найденный дефект и root cause

Первый прогон после добавления трёх пограничных случаев: TP=13, TN=19, FP=3, FN=0; precision=81,3% **на этом наборе**. Все три FP — `zero-size-interactive` для: отключённого через `fieldset` потомка, screen-reader-only кнопки с `clip: rect(0,0,0,0)`, skip-ссылки с `clip-path: inset(50%)`, видимой при фокусе. Классификатор смотрел только на явный `[disabled]` и размеры DOMRect, не учитывал эффективный `:disabled` и намеренное визуальное скрытие CSS.

Исправление `audit-engine/geometry/geometry.ts`: учитывать `:disabled` и исключать конкретные паттерны нулевой области clip/clip-path из high-confidence `zero-size-interactive`. Повторный прогон без изменения меток: FP=0, FN=0. Существующие позитивные 1×1 кнопка и ссылка всё ещё находятся.

## Проверка и границы

- `npm run verify` на Linux Node 24.19.0 / Chromium 140: static sanity, typecheck, **28 файлов / 114 тестов**, production build и runtime/UI smoke — PASS (последующая документация и временный вывод на результаты тестов не влияют).
- Benchmark код, метки и скриншоты включены для пересмотра. Метки зависят от контракта каждого сигнала и могут быть ошибочными; «100%» на 35 примерах не является гарантией.
- Не проверены реальный размеченный корпус сайтов, CSS background assets, лица и focal point, overlay contrast, все viewport и авторизованные состояния. Windows r10 — NOT VERIFIED. Следующий шаг для оценки внешней точности — независимая разметка реальных страниц и отдельный holdout-набор, который не использовался для подгонки правил.
