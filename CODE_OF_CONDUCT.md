# Code of Conduct

This project follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):

- Be welcoming, inclusive and patient — especially with first-time contributors.
- Critique code, evidence and ideas; never attack people.
- No harassment, discrimination or personal attacks in any project space.
- Assume good faith, and prefer a screenshot/log/reproduction over an argument.

Maintainers may remove content and, if necessary, restrict participation when
these standards are violated. Report unacceptable behaviour privately via
GitHub (Security/advisory channel or a direct message to the maintainer);
reports are handled discreetly.
